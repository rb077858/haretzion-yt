# הר עציון לצעירים — אתר דמו

אתר דמו סטטי (HTML/CSS/JS, ללא בנייה) לישיבה התיכונית **הר עציון לצעירים** באלון שבות.

> ⚠️ זהו אתר דמו בלבד ואינו האתר הרשמי של הישיבה. חלק מהתכנים (סדר יום, תיאורי מגמות) נכתבו להמחשה.

## דפים
- `index.html` — דף הבית
- `about.html` — על הישיבה, ציר זמן וחזון
- `staff.html` — הצוות החינוכי
- `learning.html` — בית המדרש, מגמות, סדר יום ופנימייה
- `articles.html` — מאמרים
- `contact.html` — הרשמה וקשר (טופס דמו)

## הרצה
לפתוח את `index.html` בדפדפן, או: `python3 -m http.server` ולגלוש ל-`localhost:8000`.

התמונות נלקחו מהאתר הרשמי של הישיבה (yt-haretzion.co.il) לצורך הדגמה.
